# 桌面打卡面板

Run / plan: 2026-10-30-desktop-widget / v1。路线：build；well-done；single-skewer。用户已确认视觉并要求制作。

## 已确定

- 3:4 半透明拟物玻璃，信息区不分框。左上角启动，可拖动；常规面板 420 × 560。
- 蓝色周环、绿色月环，沿用现有月内分周及工作日 × 12 小时口径，出差/休假扣减与工作台一致。
- 打卡只由用户填写起止时间，支持分段、编辑、跨午夜；与主窗口共用本地数据库。
- 心流缩为同宽横向面板，只计持续时间，不写入打卡；可选专注事项。
- 约半秒连续收拢，保留同一时钟。静置时隐藏结束按钮；键盘可访问，减少动态效果时简化过渡。
- 正式版开机只显示小面板，托盘可打开主工作台；普通启动仍可打开主工作台。默认不置顶，可切换。
- 天气首次选城市、本地记忆，可随时更改；Open-Meteo 获取当前天气，离线显示明确状态。

视觉参考：本轮已确认的 ImageGen 常规无分框图与心流专注事项图。源码实现使用原生文字、SVG 图标和 CSS 玻璃，不把图片充作界面。

## 0.8.27：等比例尺寸与灰色外层修正

用户实机截图指出尺寸过大、玻璃外侧有灰色矩形。定位为固定尺寸与原生 Acrylic 覆盖整个窗口留白。

- 原生背景改为 none，保留透明窗口；细化面板自身高光和阴影。
- 默认根据可用屏幕高度自动缩放，常见屏幕为 75%，较小工作区继续缩小；设置提供 60%–100% 手动比例。心流、文字、图标、操作区和弹层使用同一个比例。
- 原有设置读取时仅为缺少的 scale 添加默认值，城市、位置、透明度、启动偏好与专注事项保持原值。
- 类型检查、构建、相关 lint、6 项单元检查、4 项缩放交互检查及 8 项既有交互回归通过。实测自动模式为 315 × 420；两个操作区持续保持 16:9。
- 独立复核发现滑块上下方向键漏保存，修复并通过 60% → 65% → 60% 的交互回归后，结论为 Ship。
- 已在隔离窗口观察 Windows 实际显示，原生灰色外层已移除。外侧留白透明；未将测试记录写入正式库。
