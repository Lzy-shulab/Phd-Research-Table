# PhD 科研工作台设置页重构提示词

重构 Windows Electron 应用“PhD 科研工作台”的设置页。它是长期使用的科研工具，不是营销页面。延续现有“几何研究手记”设计体系、壁纸联动配色、系统字体、深浅模式、大字号、紧凑模式和减少动态效果，不替换全局视觉身份。

目标：让用户从左侧类别进入单一内容列，在数秒内找到设置、完成修改并看到就地反馈。设置类别必须与真实内容一一对应：外观与显示、桌面便签、AI 与 Codex、全文翻译、文件与数据、软件更新。

重点修改：

- 将标题和正文限制在约 1120px 的共享内容列，避免超宽屏上的长距离扫视。
- 删除“外层大卡片包内层列表”的双层结构；节标题负责说明，单一列表表面承载设置行。
- 桌面便签区直接提供六类便签的显示开关，并保留开机启动、置顶、显示面板和顺序管理。
- AI 与 Codex 区显示 Codex CLI 安装状态；未安装时提供“一键安装”，安装过程有忙碌、成功和可恢复的失败反馈。
- 文件路径使用“信息 / 路径 / 操作”稳定网格；超长路径可换行，按钮不被挤出视口。
- 全文翻译和软件更新作为低频单动作工具并列；窄窗口回到单列。
- 兼容 1100×720、18px 字号、深色模式、增强对比度和减少动态效果；视觉顺序、键盘顺序与辅助技术顺序一致。

视觉语气：安静、精准、可信。使用现有语义颜色和图标体系，以间距和排版建立层级；不增加装饰性玻璃、渐变文字、套娃卡片或无意义动画。
