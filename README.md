# PhD 科研工作台

面向科研日常工作的 Windows 桌面应用，支持项目任务与日历、文献阅读、Arxiv Daily、科研成果及论文投稿记录。

## 下载安装

进入 [Releases](https://github.com/Lzy-shulab/Phd-Research-Table/releases)，下载最新版 Assets 中的 `PhD-Research-Workbench-版本号-Setup.exe`，适用于 Windows x64。

更新前请保存并退出旧版。任务、文献和设置保存在本机。

## 功能

- 按项目管理研究任务；全部任务和 Today Plan 汇总所有项目。
- AI 识别自然语言中的日期、时间和项目并新增计划。
- 管理和阅读 PDF 文献，按需生成全文翻译或中文题目与摘要概览。
- 独立的 Arxiv Daily 文献收录页面。
- 科研成果管理及论文投稿、审稿、返修进度记录。

AI 识别和中文概览需要自行配置 API。PDF 全文翻译需要单独安装并配置 PDF2zh Next 引擎。各版本更新内容与文件校验值见对应 Release。

本仓库用于分发安装包；当前未上传应用源代码。
